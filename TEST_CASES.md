# Тест-кейсы для функционального тестирования веб-приложения

1. **Успешная авторизация:**
   - Предусловие: Регистрация нового пользователя с логином `testUser` и паролем `testPass`.
   - Шаги: Ввести логин `testUser`, пароль `testPass`, нажать "Войти".
   - Ожидаемый результат: Переход на главную страницу (home), отображение графика.
2. **Неуспешная авторизация (неверный пароль):**
   - Шаги: Ввести логин `testUser`, пароль `wrongPass`, нажать "Войти".
   - Ожидаемый результат: Отображение сообщения об ошибке ("Неверный логин или пароль").
3. **Регистрация нового пользователя:**
   - Шаги: Ввести уникальный логин `newUser`, пароль `pass1`, нажать "Зарегистрироваться".
   - Ожидаемый результат: Уведомление об успешной регистрации, автоматический вход.
4. **Регистрация с занятым логином:**
   - Ожидаемый результат: Сообщение "Пользователь с таким именем уже существует".
5. **Ввод пустых полей при логине:**
   - Шаги: Оставить форму пустой, попытаться нажать Submit.
   - Ожидаемый результат: Кнопка неактивна или появляется сообщение о необходимости заполнения.
6. **Выбор X (-3...5):** 
   - Шаги: Выбрать значение X через радиобатон.
   - Ожидаемый результат: Визуальное выделение выбранного значения.
7. **Ввод Y (-5...3):** 
   - Шаги: Ввести значение из допустимого диапазона (например, 0).
   - Ожидаемый результат: Успешная валидация поля Y.
8. **Ввод неверного Y:** 
   - Шаги: Ввести значение вне диапазона (например, 10).
   - Ожидаемый результат: Отображение ошибки для поля Y.
9. **Выбор R (1...5):** 
   - Шаги: Выбрать радиус через чекбокс или комбобокс.
   - Ожидаемый результат: Изменение масштаба графика в соответствии с выбранным радиусом.
10. **Отправка данных (Hit):** 
    - Шаги: Отправить валидные координаты.
    - Ожидаемый результат: Обновление таблицы попаданий со статусом "Hit (Попадание)".
11. **Отправка данных (Miss):** 
    - Шаги: Отправить валидные координаты за пределами фигуры.
    - Ожидаемый результат: Получение статуса "Miss (Промах)".
12. **Интерактивный клик по графику (Hit):** 
    - Шаги: Кликнуть на график внутри закрашенной области.
    - Ожидаемый результат: Появление новой точки в таблице и на холсте.
13. **Интерактивный клик (Miss):** 
    - Шаги: Кликнуть по пустой области графика.
    - Ожидаемый результат: Отсутствие изменений или появление сообщения о промахе.
14. **Клик без выбора R:** 
    - Шаги: Кликнуть по графику без установленного радиуса (если предусмотрено).
    - Ожидаемый результат: Появление предупреждения о необходимости выбора радиуса.
15. **Выход (Logout):** 
    - Шаги: Нажать кнопку выхода.
    - Ожидаемый результат: Редирект на страницу /login или /auth, удаление токена.
